Scoring

M2 D3S/EGR 2026-2027

1 Course Overview

This course is an introduction to scoring and classification. The emphasis is put on numerical examples and a hands-on, code-from-scratch approach in R.

1.1 Part 1: Methods (9h)

Statistical learning goals and vocabulary in the context of scoring and classification, followed by the study of two workhorses: Logistic Regression and Decision Trees / Boosting.

1.2 Part 2: Case Study / Project (15h)

A group project using a real-life credit risk dataset, covering the full scoring pipeline: data collection, exploration, baseline model, feature engineering, model evaluation, and advanced methods.

3 Handouts / Slides / Case Studies

Each session follows a theory -> application pattern:

  1. Slides/Handout: Concepts, definitions, theoretical foundations, and pratical examples/implementations on simple datasets using R. Compared to slides, handouts offer a higher level of detail.
  2. Case Study: Application using the Farm Holding case study, our fil rouge. We’ll use theses case studies has ungraded homeworks between lessons.

The Farm Holding case study progressively builds a complete scoring pipeline, applying each method as it is introduced in the handouts.
